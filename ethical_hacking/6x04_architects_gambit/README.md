# Nordstrøm Power Group — Architects Gambit

This project covers the engagement-architecture work for the Nordstrøm Power Group RFP. The focus is on requalifying a broad strategic brief into a defensible, phase-based consulting scope that can be priced, executed, and defended to both the client and Vanguard's commercial committee.

## Deliverables

- `2-clarification_questions.md` — structured clarification pack for pre-proposal design decisions

## Architectural posture

- commercial clarity before technical execution
- phased scope aligned to value and risk
- explicit multi-jurisdictional treatment
- recommendations framed as the architect's advice, not as an executor's unqualified mandate
